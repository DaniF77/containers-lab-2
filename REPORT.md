### 4. Выводы
В ходе работы освоены базовые команды Docker: управление образами, контейнерами, сетями и томами. Создано многоконтейнерное приложение из PostgreSQL, Go-бэкенда и Nginx, связанных общей сетью. Настроены Dockerfile с multi-stage сборкой и docker-compose для оркестрации всех сервисов с проверкой зависимостей. Реализовано автоматическое тестирование работоспособности через healthcheck. Настроен CI/CD в GitHub Actions для сборки и публикации образов в GitHub Container Registry. Образы успешно опубликованы и привязаны к репозиторию. В результате получено полностью рабочее веб-приложение, развернутое в Docker.
